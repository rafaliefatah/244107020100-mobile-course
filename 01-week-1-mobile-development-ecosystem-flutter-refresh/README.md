Refleksi:
1. Kapan native lebih tepat dipilih daripada cross-platform?
Ketika proyek membutuhkan akses mendalam dan responsif terhadap hardware spesifik dan membutuhkan penghematan memori
2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
Ketika State mengalami perubahan, Flutter akan memberi tahu sistem bahwa bagian Widget Tree terkait perlu diperbarui, lalu secara otomatis membangun ulang (rebuild) cabang Widget Tree tersebut agar sesuai dengan data State terbaru
3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
Commit kecil dengan pesan yang jelas mempermudah proses code review, melacak bug, dan mencegah merge conflict dalam tim. Bagi portofolio, pola ini membuktikan alur kerja yang terstruktur, kedisiplinan berkolaborasi, serta riwayat pemecahan masalah yang rapi kepada rekruiter
